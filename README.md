# Home Wonder Safe

Actúa como un diseñador web senior especializado en landing pages inmobiliarias de alta conversión. Crea una landing page de una sola página (single page, con scroll) para el proyecto "Home Wonder Safe", de la constructora J&M Constructora. El objetivo único de esta página es generar leads: todo el diseño debe empujar al visitante a completar el formulario de contacto. NO debe mostrarse ningún precio en la página.
